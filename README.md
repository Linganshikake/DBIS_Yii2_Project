# M.LEAGUE 立直麻将联赛信息管理系统

> 基于 Yii2 框架开发的高性能、可视化麻将职业联赛信息管理平台。

## 项目简介

本项目是以日本职业麻将联赛 **M.LEAGUE** 为背景开发的 B/S 架构信息管理系统。系统旨在为联赛提供全方位的数据管理解决方案，涵盖选手管理、队伍管理、赛程安排、新闻发布以及复杂的赛事分数统计功能。

系统前端集成了 ECharts 可视化图表，能够直观展示选手的“五维能力”雷达图和队伍的赛季得分走势。后台内置了 M.LEAGUE 官方规则的积分计算逻辑（如零和博弈校验、半决赛/决赛积分折半等），实现了从数据录入到排行榜更新的全自动化处理。

## 技术栈

* **开发框架**: PHP - Yii2 Framework (Advanced Template)
* **数据库**: MySQL 8.0 (InnoDB 引擎, 触发器, 外键约束)
* **前端技术**: Bootstrap 4, jQuery, ECharts (数据可视化)
* **运行环境**: Apache / Nginx, PHP 7.4+
* **开发环境**: XAMPP / PhpStorm / Git

## 核心功能

### 1. 前台用户端 (Frontend)

* **数据可视化**:
    * **队伍详情**: 动态展示赛季得分走势折线图，直观反映队伍晋级历程。
    * **选手详情**: 基于一位率、避四率、打点效率等数据的“五维能力”雷达图。
* **排行榜系统**:
    * 实时更新的队伍积分榜。
    * 个人 MVP 榜单与各项数据统计（最高得点、一位回数等）。
* **赛程中心**:
    * 基于日历视图的赛程查看。
    * 支持按日期回顾比赛结果与详细分数。
* **互动社区**:
    * 新闻资讯阅读与富文本展示。
    * 评论广场互动、点赞功能及个人中心管理。

### 2. 后台管理端 (Backend)

* **智能赛程管理**:
    * **分数校验**: 录入单场比赛成绩时，系统自动验证四队得分之和是否为 0，确保符合麻将零和规则。
    * **自动计算**: 成绩录入后自动触发排行榜更新，支持赛季阶段切换时的“积分折半”晋级规则计算。
* **内容管理 (CMS)**:
    * 队伍、选手、新闻信息的增删改查。
    * 支持图片与视频文件的上传与管理。
* **用户与权限**:
    * 基于 Yii2 Security 组件的 RBAC 权限控制。
    * 区分管理员（拥有完整数据权限）与普通用户。

## 部署流程 (Windows)

本项目专门开发了批处理脚本，支持在 Windows 环境下快速部署。

### 1. 环境准备
* 操作系统: Windows 10/11
* 软件要求: XAMPP (或独立安装 PHP + MySQL)
* 环境变量: 确保 `php` 和 `mysql` 命令已加入系统 PATH 环境变量。

### 2. 一键部署 (推荐)

在项目根目录下双击运行 `deploy.bat`。脚本将依次执行以下操作：
1.  **环境初始化**: 自动运行 Yii2 的 init 脚本，生成本地配置文件。
2.  **数据库连接**: 脚本会提示输入数据库用户名和密码（XAMPP 默认用户名为 `root`，密码为空，直接回车即可）。
3.  **数据导入**: 自动创建数据库 `mleague_db` 并导入完整的演示数据 (`source/data/mleague_db.sql`)。

### 3. 启动服务

部署成功后，双击 `start.bat`。脚本将启动前台和后台的 PHP 内置服务器。

* **前台首页**: `http://localhost:8080`
* **后台管理**: `http://localhost:8081`

## 安全性与优化

### 安全性设计
* **权限控制**: 实现了完善的 RBAC 权限管理，严格隔离管理员与普通用户操作接口。
* **数据加密**: 用户密码采用 bcrypt 算法哈希存储，并支持 CSRF 防护。
* **输入过滤**: 全局防止 SQL 注入与 XSS 攻击，文件上传限制格式与大小。
* **软删除机制**: 核心数据表采用 `display_status` 字段标记删除状态，而非物理删除，保障数据的可追溯性。

### 性能优化
* **数据完整性**: 数据库层面使用了严格的外键约束和 RESTRICT 级联规则，防止误删关键业务数据。
* **查询优化**: 针对 `player_id`, `team_id`, `schedule_id` 等高频查询字段建立了 B-Tree 索引，有效解决了 N+1 查询问题。

## 常见问题排查 (Troubleshooting)

如果在部署或运行过程中遇到问题，请参考以下解决方案：

**1. 端口被占用**
* **现象**: 启动 `start.bat` 时提示端口 8080 或 8081 绑定失败。
* **解决**: 打开命令行运行 `netstat -ano | findstr :8080` 查找占用进程的 PID，然后使用 `taskkill /PID <PID> /F` 结束进程，或修改 `start.bat` 中的端口号。

**2. 页面报 500 错误**
* **现象**: 访问页面显示 Internal Server Error。
* **解决**: 检查 `source/frontend/runtime` 和 `source/frontend/web/assets` 目录是否有写入权限；查看 `source/frontend/runtime/logs/app.log` 获取详细错误信息。

**3. deploy.bat 找不到 MySQL**
* **现象**: 脚本提示 `'mysql' 不是内部或外部命令`。
* **解决**: 将 MySQL 的 `bin` 目录（例如 `C:\xampp\mysql\bin`）添加到 Windows 的系统环境变量 Path 中，然后重启终端重试。
